> **版本**: v1.0

---

## 使用规则

1. **逐章自检**：每章完成后，逐项检查并勾选 `[x]`
2. **强制通过**：所有标记 `[必检]` 的项必须通过，否则不可提交审核
3. **问题记录**：未通过的项在文末记录具体问题和修正方案
4. **用户审核**：自检全部通过后提交用户审核，用户发现的问题须补充到本清单

## 八、字数检查（4 项 + 统计规则）

### 字数统计规则

**计入「字数」（每个字符算 1 字）：**
- 每个汉字 = 1 字
- 每个英文字母 = 1 字（如 `Nacos` = 5 字）
- 每个数字 = 1 字（如 `46` = 2 字）
- 代码符号（`{}();,.=<>/'"` 等）= 各算 1 字

**不计入「字数」：**
- Markdown 格式符（`**`、`#`、表格 `|`、列表 `-` 等纯格式化符号）
- Mermaid 图（` ```mermaid ... ``` `）
- ASCII 框图（┌┐└┘├┤┬┴┼─│ 等制表符组成的框图）

**示例**：`【设计背景】Nacos 是阿里巴巴开源的生产级中间件。`
- `【`(1) + `设计`(2) + `背景`(2) + `】`(1) + `Nacos`(5) + `是`(1) + `阿里巴巴`(4) + `开源`(2) + `的`(1) + `生产`(2) + `级`(1) + `中间件`(3) + `。`(1) = **27 字**

| # | 检查项 | 量化标准 | 强制 | 结果 |
|---|--------|---------|------|------|
| 8.1 | 总字数是否 ≥ 大纲目标的 80%？ | ≥ 目标 × 0.8 | [必检] | ☐ |
| 8.2 | 每小节字数是否在目标范围 ±20% 内？ | 100% 小节 | ☐ |
